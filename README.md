# 💰 Smart Personal Finance Management System

A desktop-based **Personal Finance Management System** built using **Java Swing** that helps users efficiently manage their monthly income and daily expenses. The application provides a modern graphical interface to record expenses, calculate savings, monitor budgets, and export expense history as a CSV file. :contentReference[oaicite:0]{index=0}

---

## 📌 Features

- 💵 Add Monthly Income
- 📝 Record Daily Expenses
- 🍔 Expense Categories
  - Food
  - Travel
  - Movie
  - Shopping
  - Recharge
  - Bills
- 📊 Automatic Balance Calculation
- 💰 Savings Tracker
- ⚠ Budget Exceeded Warning
- 📅 Date & Time Stamp for Every Expense
- 📥 Export Expense History to CSV
- 🗑 Delete Expense Records
- 🌙 Modern Dark Theme User Interface

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/yourusername/Smart-Personal-Finance-Management-System.git
```

2. Open the project in **Visual Studio Code**

3. Install **JDK 17**

4. Compile

```bash
javac FinanceTracker.java
```

5. Run

```bash
java FinanceTracker
```
